# RecipeHub

A Django-based recipe management app with full CRUD functionality, search, and an admin panel with role-based permissions.

## Features

- Browse all recipes (name-only list view)
- Click into a recipe for full details (ingredients + instructions)
- Add new recipes through a web form
- Delete recipes
- Search recipes by title
- Django admin panel with:
  - Custom list view (Title, Ingredients, Created By columns)
  - Search by title/ingredients
  - Groups and Users with role-based permissions
  - Automatic tracking of which user added each recipe

## Tech Stack

- Python
- Django 6.1.1
- SQLite
- HTML/CSS
